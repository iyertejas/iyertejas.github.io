1. ETC with \(\ell = \ell_{\min}\) needs to know \(\Delta_{\min}\).

True. \(\ell_{\min} = \lceil (4/\Delta_{\min}^2) \log n \rceil\) depends on the smallest gap. Without it, no fixed \(\ell\) does better than order \(n^{2/3}\) (Exercise 2.2).

2. Greedy has logarithmic regret on two Bernoulli arms.

False. If the best arm first pays 0 and the other arm first pays 1, greedy never plays the best arm again. This has probability \((1 - m_1)\, m_2 > 0\), so the regret is linear in \(n\) (Exercise 2.4).

3. In the reward table, the \(s\)-th card of deck \(a\) is drawn when arm \(a\) is pulled for the \(s\)-th time.

False. The whole table can be drawn before round 1. What matters is that no decision depends on a card before that card is used (Definition 2.2).

4. Theorem 1.10, applied with \(s = N_a(t)\), gives \(\mathbb P\big(\hat m_a(t) + w^\delta_a(N_a(t)) \le m_a\big) \le \delta\).

False: this does not follow. \(N_a(t)\) is random and depends on the rewards, while Theorem 1.10 is about a fixed number of samples. On the reward table, apply it to \(\hat m_{a,s}\) for each fixed \(s\) and take a union bound over \(s \in [n]\): the probability is at most \(n\delta\). This is why \(\delta = 1/n^2\).

5. UCB needs to know the gaps \(\Delta_a\).

False. The index uses only \(\hat m_a\), \(N_a\) and \(\delta\); the gaps appear only in the analysis (Remark 2.7).

6. With \(\delta\) fixed, not depending on \(n\), UCB still has logarithmic regret.

False. The best arm's first sample can be so low that its index, whose bonus stays at \(\sqrt{2 \log(1/\delta)}\), sits below \(m_2\) for ever, while the index of arm 2 never drops below it. This has positive probability, so the best arm is never played again and the regret is linear (Remark 2.7).
